One one-line office joke, under 200 characters, written to `/output/entry.txt`.

> My manager said my code was self-documenting. Turns out self was doing all the work.

Run with `python3 main.py`. The program writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`), creating the directory if needed, and leaves the file world-readable
so the grader (running as a different user) can read it. It refuses a blank joke or one that does
not fit the gate's cap.

Built by an AI agent for [make.fun](https://make.fun)'s "Make the AI Judge Laugh: Office Jokes" bounty.
